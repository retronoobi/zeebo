# Licenças dos runtimes Windows

Cópias sem alteração dos textos distribuídos pelo MSYS2 UCRT64 local:

- `gcc-libs/`: pacote `mingw-w64-ucrt-x86_64-gcc-libs`, versão `16.2.0-3`.
- `libwinpthread/`: pacote `mingw-w64-ucrt-x86_64-libwinpthread`, versão `14.0.0.r262.g5ea8e9fac-1`.

Usadas pelo empacotamento somente quando o arquivo correspondente não existe em `ucrt64/share/licenses`. Quando disponíveis, os textos instalados têm preferência e avisos adicionais também são copiados. Ao mudar os runtimes de compilação, revisar estas cópias. Os arquivos preservam seus copyrights e termos originais.
